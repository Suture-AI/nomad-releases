# Nomad for Mac

This repository hosts installers and update files for Nomad. It does not contain the application source code.

**A public download is not available yet.** The first release is being prepared for Apple silicon Macs running macOS 14.2 or later.

Once a release is published, download the signed and notarized DMG from [Releases](https://github.com/Suture-AI/nomad-releases/releases). Open it and drag Nomad into Applications.

Released builds check for updates in the background. When a download is ready, Nomad offers **Restart & update** or **Later**. Finish meeting recordings, Keep Mac Awake sessions, and active agent work before updating.

Each release includes a versioned DMG, the `Nomad.dmg` download alias, an update ZIP, update metadata, `SHA256SUMS`, and a release manifest. Published versions are immutable; fixes ship as a newer version. Third-party notices are included in the application.
