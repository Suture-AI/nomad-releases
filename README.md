# Nomad for Mac

## Try the friends preview

[**Download Nomad for Mac**](https://github.com/Suture-AI/nomad-releases/releases/download/nomad-v0.47.0-preview.1/Nomad-0.47.0-friends-preview-arm64.dmg)

**Apple silicon (M1 or newer) · macOS 14.2+ · Preview 0.47.0**

This is an early development preview. It is not notarized by Apple, macOS will show an unverified-app warning, and updates are manual. Start with short practice sessions; a fresh-Mac installation has not yet been verified.

- [Installation and testing guide](https://github.com/Suture-AI/nomad-releases/releases/download/nomad-v0.47.0-preview.1/Friends-Preview-Guide.md)
- [Release notes and checksums](https://github.com/Suture-AI/nomad-releases/releases/tag/nomad-v0.47.0-preview.1)

Open the DMG, drag **Nomad** into **Applications**, and open it there. If you trust the download and macOS says the developer cannot be verified, follow [Apple's app-specific Open Anyway instructions](https://support.apple.com/102445). If macOS reports damage or malware, stop and report the exact message. Do not disable Gatekeeper globally.

One installer includes the main workspace and the menu-bar companion for meeting/schedule controls, recording, and Keep Mac Awake. Use **Nomad → Keep Mac Awake…** or **Shift–Command–K** to open the companion.

Use your own AI provider account; the preview includes no AI credits or shared login. Google Calendar/Gmail setup is not ready for external testers, and longer recordings can fail with a transcription overload. Begin with a manual two-minute practice meeting. Send feedback privately to the person who invited you, using the guide; redact personal information.

## Future signed releases

The signed and notarized release with automatic updates is still being prepared. Preview users will need to manually install that first signed release. Its later updates will offer **Restart & update** or **Later**.

This repository contains release artifacts, not the application source repository. Published downloads are immutable; corrections get a new version. The friends preview is a prerelease and does not change the stable update feed. Third-party notices are included in the application.
